# Life Coach AI 项目说明

## 项目目标

创建一个基于火山方舟DeepSeek R1 API的AI人生教练网站，通过与用户的对话，提供个性化建议，帮助用户成长和解决问题。

## 项目架构

### 技术栈
- HTML5：页面结构
- CSS3：页面样式
- JavaScript：API调用和交互逻辑
- 火山方舟DeepSeek R1 API：AI对话功能

### 页面结构
1. **首页**：包含网站标题、简介和开始对话按钮
2. **对话页面**：包含对话历史、输入框和发送按钮

## 实现方式

1. **API调用**：使用JavaScript的fetch API调用火山方舟DeepSeek R1 API
2. **响应式设计**：使用CSS Flexbox和Grid实现响应式布局
3. **用户体验**：实时显示对话内容，提供友好的界面

## 使用说明

1. 打开网站首页
2. 点击"开始对话"按钮进入对话页面
3. 在输入框中输入您的问题或分享您的情况
4. 点击"发送"按钮或按Enter键发送消息
5. 等待AI回复，AI会根据您的情况提供专业建议

## 开发步骤

1. 创建HTML结构
2. 编写CSS样式
3. 实现JavaScript交互逻辑
4. 测试API调用功能
5. 优化用户体验

## 注意事项

- 本项目使用火山方舟DeepSeek R1 API，需要有效的API密钥
- 确保网络连接正常，以便API调用能够成功
- 对话内容可能会被API服务商记录，请注意隐私保护
